# Xantolo · Escuela Primaria Rafael Ramírez

Invitación web adaptable a teléfonos, tabletas y computadoras, con animaciones y ataúd interactivo.

## Configurar video
Edita `js/config.js` y asigna el enlace real a `video`.
- YouTube: `https://www.youtube.com/watch?v=ID_DEL_VIDEO`
- Archivo MP4: `video/halloween.mp4` (sube el archivo a una carpeta `video/`).

El ataúd abre un modal de reproducción real. Sin video configurado, se muestran instrucciones en lugar de un reproductor falso.

## Editar hora y lugar
Cambia `hora` y `lugar` en `js/config.js`.

## Archivos
- `index.html`: página principal
- `css/estilos.css`: diseño y animaciones
- `js/config.js`: datos del evento
- `js/efectos.js`: interacciones, video y partículas
